# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release.

| Version | Supported |
|---------|:---------:|
| Latest | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in JellyFab, please do **not** open a public GitHub issue.

Instead, report it privately by email:

**prashant.panwar777@gmail.com**

Please include:

- A description of the vulnerability
- Steps to reproduce
- A proof of concept (if available)
- The potential impact
- Any suggested mitigation or fix

I will acknowledge your report as soon as possible and work to validate and address the issue.

If the report is confirmed, a fix will be released and appropriate credit will be given (unless you prefer to remain anonymous).

Thank you for helping keep JellyFab and its users secure.
